A comprehensive library of over 150 interactive calculators with built-in SEO optimization for WordPress websites.

== Description ==

Calculator Mama is a singular, all-in-one WordPress plugin that provides a comprehensive library of over 150 interactive calculators. Its core purpose is to transform a simple utility into a powerful content marketing and organic traffic generation engine for WordPress websites.

The plugin empowers website owners to effortlessly publish high-value, interactive tools that engage visitors, increase time-on-page, and are technically optimized to rank highly in search engine results pages (SERPs). This is achieved by combining a vast calculator library with a sophisticated, built-in SEO engine.

= Key Features =

* **150+ Interactive Calculators** - Financial, Health & Fitness, Math & Science, and Other categories
* **Gutenberg Block Integration** - Easy drag-and-drop calculator insertion with live preview
* **Shortcode Support** - Universal compatibility with Classic Editor, Elementor, and other page builders
* **Built-in SEO Engine** - Automatic schema markup and meta description generation
* **Customizable Appearance** - Match calculators to your website's design
* **Responsive Design** - Works flawlessly on all screen sizes
* **Accessibility Compliant** - WCAG 2.1 AA standards
* **Performance Optimized** - Modular asset loading for minimal performance impact

= Calculator Categories =

* **Financial Calculators** - Mortgage, Loan, Retirement, Investment, Tax, and more
* **Health & Fitness** - BMI, Calorie, BMR, Pregnancy, Pace, and more
* **Math & Science** - Scientific, Fraction, Percentage, Volume, Statistics, and more
* **Other Calculators** - Age, Date, GPA, Concrete, Tip, Conversion, and more

= SEO Features =

* Automatic JSON-LD structured data generation
* Dynamic meta description creation
* Schema.org markup for better search visibility
* FAQ section support for featured snippets
* Rich content fields for enhanced SEO

= Easy Integration =

* **Gutenberg Block** - Searchable dropdown with live preview
* **Shortcode** - `[cmama_calculator slug="mortgage-calculator"]`
* **Universal Compatibility** - Works with any theme or page builder

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/calculator-mama` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to 'Calculator Mama' in your WordPress admin menu
4. Activate the calculators you want to use
5. Customize the appearance to match your website
6. Add calculators to your pages using the Gutenberg block or shortcodes

== Frequently Asked Questions ==

= How many calculators are included? =

The plugin includes over 150 calculators across four main categories: Financial, Health & Fitness, Math & Science, and Other.

= Do I need coding knowledge to use this plugin? =

No! The plugin is designed to be user-friendly. You can add calculators using the Gutenberg block or shortcodes without any coding knowledge.

= Are the calculators mobile-friendly? =

Yes, all calculators are fully responsive and work perfectly on mobile devices, tablets, and desktops.

= Can I customize the appearance? =

Yes, you can customize colors, fonts, border radius, padding, and add custom CSS to match your website's design.

= Does the plugin help with SEO? =

Yes! The plugin includes a built-in SEO engine that automatically generates schema markup and meta descriptions for better search engine visibility.

= Can I use calculators with page builders? =

Yes, the plugin works with any page builder through shortcode support, including Elementor, Beaver Builder, and others.
